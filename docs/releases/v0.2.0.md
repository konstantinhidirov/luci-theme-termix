# Termix 0.2.0 — Matrix effects

This release adds falling code, a soft glow and CRT-style scanlines to LuCI.
Go green with the new Matrix palette, or keep your usual accent: the rain
and glow follow its color. Orange works rather well.

## What you can change

There is a new **Effects** tab under **System → Termix Theme**, with one
switch at the top to turn the effect on or off. Below it you can:

- Turn glow and scanlines on or off separately.
- Put rain everywhere, over the content, or just on the sidebar and top bar.
- Choose **No code rain** if you only want glow or scanlines.
- Adjust the rain speed, character size and opacity.

Your choices are kept when you turn the effect off.

The Matrix palette is separate from the effects switch. Its saturation
defaults to **60%**, which gives a softer green. Turn it up to **100%** for
the original vivid green, or down to **0%** for white text and accents.
Lowering saturation blends toward white instead of making the text darker.

## A few practical details

Effects are **off by default** and run only in dark mode. They pause in
hidden tabs, while a LuCI dialog is open, and when your device requests
reduced motion.

The code rain uses Unicode characters and system fonts. Everything ships
with the theme; there are no font downloads or external requests for the
effect. The animation runs in your browser.

This release also fixes thick bands between table records on mobile.
The rain accounts for high-DPI screens and the mobile sidebar opening and
closing.

## Install or upgrade

Download `luci-theme-termix-0.2.0-r1.apk` and install it over SSH or through
LuCI's package manager:

```sh
apk add --allow-untrusted ./luci-theme-termix-0.2.0-r1.apk
```

Existing appearance settings are preserved. Reload the browser after
upgrading. To try the new effects, open **System → Termix Theme → Effects**,
enable them, apply and reload again.

Built with the OpenWrt 25.12.5 SDK and checked on OpenWrt 25.12.5 with LuCI
26.273.20498~1fcad1e. The APK is architecture-independent (`noarch`).
Older OpenWrt releases need an IPK built with their corresponding SDK;
an IPK is not included in this release.
